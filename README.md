# TechMids Conf 2026 micro site

A single-page, mobile-first itinerary for TechMids Conf 2026 (Fri 27 Nov 2026, Everyman Cinema, The Mailbox, Birmingham).

- Live NOW / NEXT banner using Europe/London time, with room-change callouts between screens
- "Connect on LinkedIn" button that opens a fullscreen QR code (tap to close)
- Fully self-contained `index.html`: no CDN, fonts or network calls, so it works offline

Open `index.html` in any browser, or serve it with GitHub Pages from the repository root.

Full conference agenda: https://conf.techmids.org
